There is no model training in this project. Speech Arena doesn't train a neural network. It uses a pretrained model (MMS_FA) to find when each word is spoken, then compares pitch, loudness and pace against a reference recording using fixed rules. So instead of training progress, this page shows how much of the build is real, partly done, or a placeholder.
